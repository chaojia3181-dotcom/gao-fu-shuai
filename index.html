📚 交易原则参考

🎯 选择标的

  • 高富帅：增仓 + 放量 + 上涨 → 选多点
  • 白富美：增仓 + 放量 + 下跌 → 选空点
  • 底部三角形有大行情，可翻3倍
  • 岛型反转：常规3-5天，特殊10天内

📐 判断趋势

  • 三步判断顶和底：破趋势线 → 反弹不创新高 → 破颈线
  • 上升趋势线连接连续回调低点
  • 管道线：从A点向右画平行线
  • 震荡用摆动指数，趋势用移动平均线

💰 仓位管理

  • 固定风险比率 2-5%，按损定量
  • 金字塔加码：每次加上一次的60-80%
  • 破加 → 回加 → 再破加
  • 首次开仓30%，确认后逐步加仓

🛡️ 止损止盈

  • 止损位坚决不变，止盈位随时调整
  • 破21线平；破颈线全平；破趋势线全平
  • 连拉3-5大阳：3根跑一半，5根全平仓
  • 时间止损：波段3天，分钟8根K线

📏 目标测算

  • 形态行情：第一目标位 = 原形态高度的一倍
  • 三角形：最宽处从突破点顺势测量
  • 管道线目标：加2-3根管道线
  • 不吃鱼头和鱼尾，只吃2.5根线

⚠️ 风险控制

  • 一定顺势交易，去读趋势跟踪
  • 一定要有止损，活下去
  • 一定要轻仓，逐步加仓
  • 一定要过滤：RSI 80以上/20以下看蜡烛图
