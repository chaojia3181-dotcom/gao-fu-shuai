# 📊 期货八种形态 · 北大策略扫描

每天自动扫描 54 个期货主力连续合约，基于**成交量、持仓量、价格**三个维度，将品种分类为八种形态，辅助交易决策。

> 理论来源：北大期货班 · 王刚老师课程 ——「三仆是臣」共振原则

---

## 🔲 八种形态矩阵

基于三个维度（价格方向 × 成交量方向 × 持仓量方向）的组合：

| 形态 | 价格 | 成交量 | 持仓量 | 信号 | 操作含义 |
|------|------|--------|--------|------|----------|
| 🏆 **高富帅** | 上涨 | 放量 | 增仓 | 强上涨信号 | 新资金涌入，多头进攻，选多点 |
| 💎 **白富美** | 下跌 | 放量 | 增仓 | 强下跌信号 | 新资金做空，空头打压，选空点 |
| ⚠️ **上涨乏力** | 上涨 | 放量 | 减仓 | 上涨乏力 | 老多头获利了结，警惕反转 |
| 🛑 **下跌乏力** | 下跌 | 放量 | 减仓 | 下跌乏力 | 老空头获利了结，跌势暂缓 |
| 🔶 **虚涨分歧** | 上涨 | 缩量 | 增仓 | 虚涨/分歧 | 多空分歧加大，需观望 |
| 🔷 **虚跌分歧** | 下跌 | 缩量 | 增仓 | 虚跌/分歧 | 多空分歧加剧，趋势不明 |
| 📉 **涨势将尽** | 上涨 | 缩量 | 减仓 | 涨势将尽 | 多头力量衰退，趋势将结束 |
| 📈 **跌势将尽** | 下跌 | 缩量 | 减仓 | 跌势将尽 | 空头力量衰退，或迎反转 |

## 📐 核心原则（来自北大课程）

### 三仆是臣
- **成交量、持仓量**是「仆」，验证「价格」这位「主」的有效性
- 三仆与主方向一致 → 趋势最健康，大胆操作
- 三仆与主方向背离 → 高度警惕

### 选择标的
- 高富帅：增仓 + 放量 + 上涨 → **选多点**
- 白富美：增仓 + 放量 + 下跌 → **选空点**
- 底部三角形有大行情，可翻3倍
- 岛型反转：常规3-5天，特殊10天内

### 判断趋势
- 三步判断顶和底：破趋势线 → 反弹不创新高 → 破颈线
- 上升趋势线连接连续回调低点
- 震荡用摆动指数，趋势用移动平均线

### 仓位管理
- 固定风险比率 2-5%，**按损定量**
- 金字塔加码：每次加上一次的 60-80%
- 破加 → 回加 → 再破加

### 止损止盈
- **止损位坚决不变**，止盈位随时调整
- 破21线平；破颈线全平；破趋势线全平
- 连拉3-5大阳：3根跑一半，5根全平仓
- 时间止损：波段3天，分钟8根K线

### 目标测算
- 形态行情：第一目标位 = 原形态高度的**一倍**
- 管道线目标：加2-3根管道线
- 不吃鱼头和鱼尾，只吃2.5根线

## 🚀 快速开始

### 本地运行

```bash
# 1. 克隆仓库
git clone https://github.com/<你的用户名>/gao-fu-shuai.git
cd gao-fu-shuai

# 2. 安装依赖
pip install -r requirements.txt

# 3. 运行扫描
python scan.py

# 4. 打开网页
# 直接用浏览器打开 index.html（需要 data.json 数据文件）
```

### GitHub Pages 自动部署

1. Fork 本仓库到你的 GitHub 账号
2. 进入仓库 **Settings → Pages**
3. Source 选择 **GitHub Actions**
4. 进入 **Actions** 页面，启用 Workflows
5. 每天 15:35（北京时间）自动执行扫描并部署

> 首次部署后，访问 `https://<你的用户名>.github.io/gao-fu-shuai/` 即可查看。

## 📊 数据来源

- **新浪财经期货主力连续合约**
- 使用 [akshare](https://www.akshare.xyz/) 库获取数据
- 扫描 54 个品种（上期所、大商所、郑商所、中金所、广期所）
- 取最近 60 天日K线数据，计算 5日/20日平均成交量
